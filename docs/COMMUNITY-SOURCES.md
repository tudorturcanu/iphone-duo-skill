# Sources behind the visual developer guide

Platform sources reviewed October 26, 2026.

## Primary sources

- [Designing for iPhone Duo](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo): displays, controls, reserved regions, and layout principles.
- [Preparing your app for iPhone Duo](https://developer.apple.com/documentation/technologyoverviews/preparing-your-app-for-iphone-duo): implementation guidance.
- [Three steps to make your app shine](https://developer.apple.com/iphone-duo/prepare/): SDK tiers and preparation workflow.
- [Xcode 27.2 RC release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-27_2-release-notes): version-specific simulator limitations.
- [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications): submission assets and the April 2027 requirement.
- [ReservedRegion](https://developer.apple.com/documentation/swiftui/reservedregion), [ArrangementView](https://developer.apple.com/documentation/swiftui/arrangementview), and [NavigationSplitView](https://developer.apple.com/documentation/swiftui/navigationsplitview): API references.

## How to read the guide

The explorer is an educational browser diagram, not an iOS simulator. Display proportions, gutter sizes, and control dimensions are illustrative. Pose choices explain behavior; they do not recommend pose-based branches or fixed hinge thresholds in app code. Split View traits must be read from the actual view. Camera and fold guides can be toggled to understand their roles.

Code cards are labeled patterns or excerpts. App-specific view names and actions are placeholders. The full tutorial contains the verified edits to the bundled Notes fixture. Its audit counts are recorded example results, not an audit of the visitor's app.

Apple's documents provide the platform API guidance. Content is a reviewed snapshot dated above, not a live feed or a scheduled monitor. No third-party code or media was copied into the site.
